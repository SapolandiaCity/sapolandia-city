# Sapolandia.city — Cassino Demo

Site estático demonstrativo, pronto para GitHub Pages.

## Publicar
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e `README.md`.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha `main` e `/ (root)`, salve.
6. Aguarde o endereço aparecer na seção Pages.

## Limites
Este projeto é somente uma interface/demo com saldo fictício. Não implementa apostas com dinheiro real, pagamentos, saques, contas seguras ou RNG certificado. GitHub Pages hospeda arquivos estáticos e não é backend de apostas.
