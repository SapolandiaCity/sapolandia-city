# Sapolandia Play

Plataforma de jogos gratuitos (React + TypeScript + Vite + Tailwind + Supabase).
Fichas virtuais, sem dinheiro real, sem depósito e sem saque.

## Stack

React 18, TypeScript, Vite, Tailwind CSS, React Router, Zustand, React Hook Form + Zod, Supabase (Auth, Postgres, Storage, RLS), Lucide.

## Rodar local

```bash
npm install
cp .env.example .env   # preencha as chaves
npm run dev
